# log-decision

Дописать в конец `DECISIONS.md` (SPEC 8.2):

```
## ГГГГ-ММ-ДД ЧЧ:ММ · поток X · файл
Вопрос: ...
Решение: ...
Почему: ...
Обратимо: да/нет (где поменять)
```

Запрос к оркестратору (нужно изменить контракт `src/contracts.py`, общий конфиг или файл другого потока):

```
## ГГГГ-ММ-ДД ЧЧ:ММ · поток X · ЗАПРОС → оркестратор
Файл: ...
Что нужно: ...
Зачем: ...
Статус: открыт
```

После запроса — остановиться на этом месте и продолжать только с другой частью работы.
Если решение необратимо, стоит денег, меняет то, что увидит жюри, или варианты расходятся > 5 п.п. — спросить человека (SPEC 8.3).
